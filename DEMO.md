# Демонстрация прототипа «Окно»

**Автор проекта — Антон Шишкин.**

Запустите `python app.py` и откройте [локальный интерфейс](http://127.0.0.1:8000). Для быстрого просмотра есть [21-секундное видео](docs/okno-prototype-demo.mp4).

## Сценарий показа

1. Нажмите **«Загрузить демоданные»**. Появятся четыре заявки вымышленных клиентов.
2. В режиме **«Администратор»** добавьте окно на стрижку **16:00–17:30**. Подбор найдёт Анну и Игоря. Марии нужна другая услуга, Олег может прийти только с 18:00.
3. В режиме **«Клиент»** выберите Анну и нажмите **«Мне подходит»**. Затем вернитесь в кабинет администратора и подтвердите её отклик.
4. Покажите статус **«Ваша запись подтверждена»** в профиле Анны. Затем переключитесь на профиль Игоря: окно уже занято. После обновления страницы подтверждение сохранится.

## Дополнительные проверки

- Чтобы проверить, что подбор зависит от данных, измените удобное время Олега с 18:00 на 16:00, сохраните заявку и создайте новое окно на стрижку с 16:15 до 17:45. Олег появится среди подходящих клиентов.
- Чтобы проверить два отклика, на открытое окно сначала откликнитесь за Анну и Игоря, затем подтвердите одного. Сервер закроет окно для второго клиента.

Сейчас предложения приходят в браузерный кабинет клиента. На пилоте планирую измерить долю состоявшихся визитов на освободившееся время и время, которое администратор тратит на поиск замены.
