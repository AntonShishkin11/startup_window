# Окно

Учебный прототип для груминг-салонов. Когда клиент отменяет визит, администратор добавляет свободное окно. Сервис находит людей, которые заранее выбрали нужную услугу и готовы прийти в этот интервал. Клиент откликается, а администратор подтверждает одну запись.

**Гипотеза.** Подбор по услуге и времени позволяет предлагать освободившееся окно подходящим клиентам и подтверждать замену без ручного перебора списка. Прототип проверяет механику подбора и отклика. Экономию времени и готовность клиентов откликаться предстоит проверить на пилоте.

## Локальный запуск

Нужен Python 3.10 или новее. Установка пакетов, интернет и ключи API не требуются.

Откройте терминал в папке с `app.py` и запустите:

```bash
python app.py
```

Если команда не найдена, используйте `py -3 app.py` на Windows или `python3 app.py` на macOS/Linux. Откройте [http://127.0.0.1:8000](http://127.0.0.1:8000). Для остановки нажмите Ctrl+C. Если порт занят, укажите другой: `python app.py --port 8001`.

## Демонстрация

1. Нажмите **Загрузить демоданные**. В листе ожидания появятся четыре вымышленных клиента с разными запросами на завтра.
2. В режиме **Администратор** добавьте предложенное окно **Стрижка, 16:00–17:30**. Анна и Игорь получат предложение, а Мария и Олег не попадут в подбор: Мария указала другую услугу, Олег может только с 18:00.
3. Переключитесь в режим **Клиент**, выберите Анну и нажмите **Мне подходит**. Для проверки двух откликов повторите это в профиле Игоря.
4. В режиме администратора подтвердите Анну. Окно закроется. В профиле Анны появится подтверждение, в профиле Игоря — статус «Окно уже занято».
5. Обновите страницу: запись сохранится.

Можно проверить другой сценарий: измените заявку клиента, сохраните её и создайте новое окно. Подбор выполняется по заявкам, существующим на момент добавления окна. Кнопка демоданных сбрасывает текущие заявки и окна после подтверждения.

## Как устроено

- **Клиентская часть:** HTML, CSS и JavaScript. Режимы администратора и клиента используют один сервер.
- **Сервер:** Python, стандартный HTTP-сервер и SQLite. База создаётся в `data/okno.sqlite3`. Заявки, окна, предложения и подтверждения сохраняются после перезапуска.
- **Правило подбора:** совпадают услуга и дата, весь интервал окна помещается в указанное клиентом время. Подбор выполняется запросом к SQLite.
- **Подтверждение:** администратор может выбрать только клиента с откликом. Сервер записывает подтверждение в транзакции, поэтому два отклика не могут занять одно окно.
- **Границы прототипа:** предложения приходят в браузерную вкладку клиента. Для теста роли и вымышленные профили переключаются в одном браузере. Подключение Telegram, авторизация и синхронизация с CRM — задачи следующих версий. Сервер слушает только локальный адрес.
