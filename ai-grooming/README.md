# ИИ-администратор груминг-салона «Лапа»

Учебный агент на n8n. Клиент пишет в отдельном веб-чате, а агент объясняет, что входит в услугу, или задаёт уточняющий вопрос. «Лапа» — вымышленный салон с учебными данными.

## Как работает

1. **Запрос из веб-чата** — Webhook принимает POST-запрос из отдельного приложения.
2. **Очистить запрос** — убирает лишние пробелы и проверяет длину.
3. **Запрос корректен?** — направляет корректный вопрос к модели, остальные запросы — в ветку ошибки.
4. **Добавить правила салона** — добавляет справку об услугах и инструкции для модели.
5. **Qwen · языковая модель** — отправляет запрос в локальную Qwen2.5 через HTTP.
6. **Проверить ответ модели** — проверяет наличие текста и готовит JSON для чата.
7. **Сообщить об ошибке ввода** — готовит ответ для некорректного запроса.
8. **Вернуть ответ в веб-чат** — возвращает текст или ошибку через HTTP.

## Запуск

Нужны [Node.js 22 или 24](https://nodejs.org/), Python 3.10+ и [Ollama](https://ollama.com/download). Модель бесплатная и не требует ключа. Первое скачивание модели и n8n требует интернета.

1. Запустите Ollama. Если она уже работает в фоне, второй сервер запускать не нужно. Скачайте модель:

   ```bash
   ollama pull qwen2.5:1.5b
   ```

2. В отдельном терминале запустите n8n:

   ```bash
   npx n8n@2.47.7
   ```

3. Откройте [редактор n8n](http://127.0.0.1:5678). При первом запуске создайте локального владельца. Создайте workflow, в меню **⋯** выберите **Import from File**, откройте `workflow.json`, сохраните и нажмите **Publish**.
   Если редактор показывает опубликованный workflow, а вебхук отвечает 404, перезапустите тестовый n8n с `N8N_USE_WORKFLOW_PUBLICATION_SERVICE=false` и перепубликуйте схему. В PowerShell задайте переменную перед запуском: `$env:N8N_USE_WORKFLOW_PUBLICATION_SERVICE="false"`.

4. В папке проекта запустите чат:

   ```bash
   python chat.py
   ```

   На Windows при необходимости используйте `py -3 chat.py`, на macOS/Linux — `python3 chat.py`.
5. Откройте [веб-чат](http://127.0.0.1:8008) и задайте вопрос. Чат отправляет запрос в опубликованный вебхук `/webhook/grooming-ai`. Туннель не нужен, поскольку чат и n8n работают на одном компьютере.

## Как показать работу

В редакторе откройте опубликованную схему и покажите восемь нод. Затем откройте чат и задайте два разных вопроса:

- «Что входит в полный комплекс для йорка?»
- «У корги сильно линяет шерсть. Что входит в экспресс-линьку?»

В первом случае ответ должен описать уход со стрижкой, во втором — уход с вычёсыванием. Вкладка **Executions** позволяет открыть выполненный запуск и показать результат ноды Qwen. При локальном запуске скорость ответа зависит от компьютера.

В записанной демонстрации ту же модель **Qwen2.5-1.5B-Instruct** в формате GGUF обслуживал **llama.cpp** через локальный HTTP-адаптер с форматом Ollama Chat API. При запуске по инструкции выше этот же workflow обращается к Ollama.

Документация: [n8n через npm](https://docs.n8n.io/hosting/installation/npm/), [Qwen2.5 в Ollama](https://ollama.com/library/qwen2.5), [формат Chat API](https://docs.ollama.com/api/chat).
